# Dependencies for running the vendored detectron2 fork (detectron2.zip,
# extracted to ./detectron2/) and tools/*.py in this repo.
#
# Setup:
#   python3 -m venv .venv-smoke
#   source .venv-smoke/bin/activate
#   pip install -r requirements.txt
#   pip install torch torchvision   # see note below -- deliberately separate
#
# torch/torchvision are NOT pinned here on purpose: which wheel you want
# depends on your hardware.
#   - macOS: `pip install torch torchvision` from plain PyPI already gets the
#     right (CPU/MPS) build.
#   - Linux CPU-only: `pip install torch torchvision --index-url
#     https://download.pytorch.org/whl/cpu` (plain PyPI defaults to a much
#     larger CUDA-bundled wheel even with no GPU).
#   - Linux + CUDA (needed for any real training run, see project notes on
#     expected training time): install the build matching your CUDA version
#     per pytorch.org's own selector.
# Verified working together in this environment at time of writing: torch
# 2.13.0 / torchvision 0.28.0 (CPU). detectron2's compiled C++/CUDA extension
# (detectron2._C -- DeformConv, rotated ROIAlign/NMS) is NOT built against
# whatever torch you install; see detectron2/_C.py (a stub -- those specific
# ops are unused by RankSaliencyNetwork/SalientDetector) and
# detectron2/layers/roi_align.py (rewired to torchvision.ops.roi_align).
# Building the real extension is only needed if you touch code paths outside
# this project's actual model (rotated boxes, deformable conv).
